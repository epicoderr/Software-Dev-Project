# Purpose
To build a program that plays the game Minesweeper

# Features
The ability to play the game Minesweeper

# Core functionality:
The core is the minesweeper game itself. The core functionality of that is the ability to generate a new, solvable puzzle each time a player chooses to play. This can be split into even more functionalities, like generating the placements of the bombs and the tiles around them. The board is tracked accurately and the player is able to reveal and flag tiles as they like. The player may also restart the game if they choose to do so.
